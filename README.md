# What the app does

- Shows a map and list with the same filtered places.
- Draws markers inside the current map view, with pine trees for trails and parks.
- Searches names, towns and activity descriptions.
- Filters food, shops, parks, trails, attractions and events.
- Sorts by name or straight-line distance from downtown Portland.
- Opens the Events filter in chronological order, with the earliest dates and times first.
- Merges matching names at nearby coordinates while preserving separate branches and distinct events.
- Loads providers independently so a failure does not erase other results.
- Uses a blurred collage of ten Greater Portland photos and features the Portland Hearts of Pine and Valentine Bandit tradition. Photo credits and licenses are listed on the page under Data sources.
